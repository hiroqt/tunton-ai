# Interface Review Heuristics

Use these as questions, not a scorecard to mechanically satisfy.

## Clarity
- Can the user tell what this screen is for?
- Are the most important actions visually and semantically obvious?
- Are labels specific rather than vague?

## Interaction
- Does each control communicate what it does?
- Can users discover important actions without hover-only behavior?
- Are unavailable actions explained when explanation is useful?

## State
- Can users tell what is currently selected, saved, loading, failed, or complete?
- Does the UI distinguish "not started" from "in progress"?
- Are partial and mixed states handled where applicable?

## Feedback
- Does every meaningful action receive timely acknowledgement?
- Does feedback appear where users will notice it?
- Can users recover from common failures?

## Accessibility
- Is keyboard operation possible where relevant?
- Is focus visible?
- Are semantics and announcements appropriate?
- Does the experience remain understandable without color?

## Responsive behavior
- What happens when content wraps, space decreases, or touch replaces precise pointing?
- Are important actions still reachable and understandable?

## Visual hierarchy
- Is emphasis proportional to importance?
- Are related things grouped and unrelated things separated?
- Is density appropriate for the task?
