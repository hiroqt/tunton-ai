# Destructive Actions

**Category:** interaction
**Source:** https://designmotionhq.com/patterns/destructive-actions
**Verification:** direct-page

> Dangerous actions are a design language, not just a red button.

## Core principle

Destructive actions need a visual and behavioral language that adds friction without becoming pointless ceremony.

## Rules

- Name the destructive action directly on the control.
- Reserve red for destruction so its meaning stays strong.
- Separate destructive actions from routine confirmation positions.
- Use labeled danger zones for high-risk settings.
- For truly irreversible operations, provide a grace period when the product allows it.
- Use stronger gestures such as hold-to-confirm only where they genuinely reduce accidental activation.

## Do

- Make destructive intent explicit.
- Use deliberate placement and confirmation friction proportional to risk.
- Offer recovery time when possible.

## Don’t

- Use generic “Are you sure?” copy as the only safeguard.
- Put delete where users expect the normal confirm action.
- Dilute destructive color by using it everywhere.
