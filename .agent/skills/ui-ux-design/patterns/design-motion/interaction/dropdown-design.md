# Dropdown Design

**Category:** interaction
**Source:** https://designmotionhq.com/patterns/dropdown-design
**Verification:** direct-page

> Your dropdown is broken. Five rules separate cheap from premium.

## Core principle

Dropdowns need an obvious trigger, viewport-aware placement, keyboard control, scalability for long lists, and restrained motion.

## Rules

- Give the trigger a comfortable touch target and clear affordance.
- Flip placement when there is insufficient space.
- Support keyboard navigation, Enter, and Escape.
- Add search when option sets become long.
- Use a short, purposeful open animation.

## Do

- Make the trigger clearly interactive.
- Keep the menu on-screen.
- Support keyboard input.

## Don’t

- Use tiny, ambiguous triggers.
- Allow long menus to clip.
- Ship a menu that only works with a pointer.
