# Date Pickers

**Category:** forms
**Source:** https://designmotionhq.com/patterns/date-pickers
**Verification:** direct-page

> Same date. Six clicks. Or one. The picker that respects your users' time.

## Core principle

Date selection should minimize effort for common cases and provide a fast, legible path for custom ranges across desktop, keyboard, and touch.

## Rules

- Provide common presets for frequent date ranges.
- Make range selection visibly previewable before the end date is committed.
- Show adjacent months side by side for cross-month ranges.
- Support keyboard navigation and direct date entry where practical.
- Use a touch-friendly full-screen/mobile surface instead of a cramped popover.

## Do

- Optimize for common date ranges.
- Keep range selection legible.
- Design keyboard and touch interactions intentionally.

## Don’t

- Force repeated month navigation for nearby dates.
- Make custom range selection require hidden or ambiguous gestures.
- Treat mobile as a scaled-down desktop picker.
