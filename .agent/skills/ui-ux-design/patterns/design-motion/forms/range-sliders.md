# Range Sliders

**Category:** forms
**Source:** https://designmotionhq.com/patterns/range-sliders
**Verification:** direct-page

> Drag to 47. Or 48? Your finger can't tell.

## Core principle

Sliders are imprecise input devices, especially on touch. Increase the effective target, keep the value visible, and add snapping/keyboard control when exact values matter.

## Rules

- Show the filled portion of the track as a value cue.
- Expand the interactive target beyond a thin visual track.
- Snap to meaningful steps when precision matters.
- Show the exact value during interaction.
- Support keyboard control for accessible operation.

## Do

- Make the entire slider row easy to grab.
- Keep the current value readable.
- Support arrow/Home/End keyboard behavior.

## Don’t

- Make a few-pixel hairline the only hit target.
- Use uncontrolled continuous precision when users need clean increments.
- Ship without keyboard interaction.
