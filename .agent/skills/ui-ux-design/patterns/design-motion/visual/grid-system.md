# Grid System

**Category:** visual
**Source:** https://designmotionhq.com/patterns/grid-system
**Verification:** direct-page

> Align everything to a 12-column grid, then break it on purpose.

## Core principle

A consistent grid creates alignment and rhythm. Use a flexible column system, responsive breakpoints, and deliberate exceptions rather than arbitrary placement.

## Rules

- Start from a 12-column desktop mental model when appropriate.
- Use simple ratios for common layouts.
- Treat gutters as part of the visual tone.
- Reduce the column count progressively at smaller breakpoints.
- Break the grid intentionally when emphasis benefits from it.

## Do

- Align shared edges.
- Define responsive grid behavior.
- Use grid-breaking moments deliberately.

## Don’t

- Place elements arbitrarily without alignment logic.
- Assume desktop columns can simply shrink on mobile.
