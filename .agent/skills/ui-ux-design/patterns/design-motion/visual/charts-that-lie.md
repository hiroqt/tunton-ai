# Charts That Lie

**Category:** visual
**Source:** https://designmotionhq.com/patterns/charts-that-lie
**Verification:** direct-page

> Same data, opposite stories: how you draw a chart decides which truth people see.

## Core principle

Data visualization is an interaction with truth: scale, chart type, aspect ratio, decoration, color encoding, and titles can all distort interpretation.

## Rules

- Use an honest zero baseline for bar charts when appropriate.
- Choose chart types based on the analytical question.
- Avoid aspect ratios that exaggerate or flatten trends.
- Maximize data-ink and remove decorative noise.
- Use color as a deliberate encoding system.
- Write titles that communicate the takeaway when appropriate.

## Do

- Make comparisons visually proportional.
- Choose a form that matches the question.
- Label important data directly where practical.

## Don’t

- Truncate bar-chart baselines to exaggerate differences.
- Use decorative 3D effects that distort values.
- Use color purely as decoration.
