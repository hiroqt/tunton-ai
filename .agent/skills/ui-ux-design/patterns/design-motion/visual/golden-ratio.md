# Golden Ratio

**Category:** visual
**Source:** https://designmotionhq.com/patterns/golden-ratio
**Verification:** direct-page

> One layout looks cheap, the other expensive. The difference is 1.618.

## Core principle

The golden ratio can be used as a proportional design heuristic for spacing, type scales, and split layouts, but it should yield to content and an established spacing system.

## Rules

- Use 1.618 as an optional proportional reference, not a rigid law.
- Apply it to related scales when a coherent rhythm is helpful.
- Round values to practical design tokens.
- Prefer established grid/spacing consistency over forced mathematical purity.

## Do

- Use proportions to create a coherent rhythm.
- Adapt the ratio to real content.

## Don’t

- Apply 1.618 mechanically when it harms usability or conflicts with the product grid.
