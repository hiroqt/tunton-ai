# Reverse-Engineered Linear

**Category:** visual
**Source:** https://designmotionhq.com/patterns/reverse-engineered-linear
**Verification:** direct-page

> Why does Linear feel expensive? Five decisions. None need a designer.

## Source-derived guidance

Design Motion analyzes a set of interface decisions associated with Linear: higher information density, restrained typography, depth created through stacked background values rather than heavy shadows, a limited accent color, visible keyboard shortcuts, fast hover feedback and short transitions, and disciplined 4px-grid alignment. The page presents these as concrete design decisions to study, not as a requirement to copy Linear's visual identity.

## Core principle

Perceived polish can come from disciplined hierarchy, density, alignment, restrained color, and responsive feedback rather than decorative effects.

## Rules

- Use density deliberately so more information fits without sacrificing legibility.
- Treat surface values and borders as viable hierarchy tools instead of defaulting to drop shadows.
- Limit accent color to meaningful emphasis rather than coloring every status or control.
- Expose useful keyboard shortcuts where the product has frequent keyboard-driven actions.
- Keep interaction feedback quick and transitions restrained when the interaction calls for immediate response.
- Use a consistent spacing/alignment grid and align content according to its type rather than centering everything.

## Do

- Use a small, deliberate set of surface values to create depth.
- Align labels and identifiers consistently and align numeric/date data according to its reading pattern.
- Use shortcuts and fast feedback as part of the interaction model when appropriate.
- Treat the 4px grid as a reference for disciplined spacing, not a reason to break product-specific constraints.

## Don't

- Copy Linear's branding or aesthetic merely because the pattern is named after it.
- Use shadows everywhere when simpler surface hierarchy communicates depth.
- Turn every status or priority into a bright colored pill when a quieter cue would be clearer.
- Add bounce, overshoot, or long transitions to routine interface feedback without a user-centered reason.

## Agent action

When a product UI feels visually inconsistent or overly decorative, inspect density, surface hierarchy, accent usage, alignment, shortcuts, and feedback timing as separate design axes. Improve the weakest axis using the existing product's design system rather than copying Linear wholesale.
