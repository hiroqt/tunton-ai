# Empty States

**Category:** content
**Source:** https://designmotionhq.com/patterns/empty-states
**Verification:** direct-page

> Your empty state is your first impression. Most apps waste it.

## Core principle

An empty state should explain why nothing is present and give the user a meaningful next action instead of looking like a broken page.

## Rules

- Signal that the empty state is intentional.
- Use human, context-specific copy.
- Provide a primary next-step action.
- Distinguish first-run, no-results, error, and filtered-out states.
- Use the empty state as an onboarding opportunity when appropriate.

## Do

- Explain the situation and next step.
- Give a clear primary CTA.
- Match the message to the reason for emptiness.

## Don’t

- Show a blank screen with no explanation.
- Reuse one generic empty-state message for every scenario.
- Make “refresh” the default answer when there is a better next action.
