# Easing Curves

**Category:** motion
**Source:** https://designmotionhq.com/patterns/easing-curves
**Verification:** direct-page

> Same distance, different feel: the easing curve is what decides how motion reads.

## Core principle

Easing changes the perceived character of motion even when distance and duration stay the same. Consistency matters more than collecting many curves.

## Rules

- Use linear mainly for continuous motion rather than UI enter/exit.
- Use ease-out as a strong default for entrances.
- Use spring/bounce selectively for moments that benefit from liveliness.
- Reuse a small, coherent set of curves throughout the product.

## Do

- Choose easing based on intent.
- Keep motion language consistent across components.

## Don’t

- Use linear as a default for start/stop UI motion.
- Give every component a different easing personality.
