# Animation Timing

**Category:** motion
**Source:** https://designmotionhq.com/patterns/animation-timing
**Verification:** direct-page

> Same modal, two timings: one feels premium, one feels broken. It's all milliseconds.

## Core principle

Motion timing shapes perceived quality and responsiveness. Entrances can be slower than exits, direct feedback should be nearly immediate, and attention motion can be longer.

## Rules

- Use roughly 200–300ms for common entrances as a starting point.
- Make exits faster than entrances.
- Give press/tap feedback very quickly.
- Use longer motion for deliberate attention-grabbing moments.
- Stagger list items subtly rather than making the whole list crawl.
- Use easing that matches the motion’s intent.

## Do

- Use responsive entrance/exit timing.
- Keep direct interaction feedback fast.
- Use consistent timing conventions across the product.

## Don’t

- Stretch routine entrances until they feel obstructive.
- Use identical in/out timing by default.
- Use linear easing as the default for UI enter/exit motion.
