# Recognition Over Recall

## Core Principle
Interfaces should expose relevant choices, context, and system state so users can recognize
what they need instead of remembering hidden commands or prior information.

## Agent Action
- Prefer visible labels, previews, examples, and contextual options over hidden requirements.
- Preserve useful context when moving between steps or views.
- Avoid making users remember IDs, syntax, or previous values when the interface can show them.

## Do
- Make options discoverable at the point of decision.
- Reuse visible context and meaningful labels.

## Don't
- Hide essential actions behind obscure gestures or unexplained shortcuts.
- Require unnecessary memorization.
