# Progressive Disclosure

## Core Principle
Show the information and controls needed for the current decision first, while keeping
secondary detail available without overwhelming the primary task.

## Agent Action
- Identify primary versus secondary information.
- Keep routine actions close to the main task.
- Reveal advanced options only when they become relevant or requested.
- Preserve discoverability so secondary functionality is not effectively hidden.

## Avoid
Do not use progressive disclosure to hide information users need to make an informed decision.
