# Page UX Review Checklist

- [ ] User goal is obvious
- [ ] Information hierarchy matches task priority
- [ ] Navigation/location is understandable
- [ ] Empty, loading, error, success, and partial states are intentional
- [ ] Primary actions remain discoverable across input methods and breakpoints
- [ ] Forms explain requirements and validation at useful times
- [ ] Feedback and recovery are consistent
- [ ] Content is scannable and terminology is clear
- [ ] Accessibility semantics, focus, contrast, and announcements are appropriate
- [ ] Layout remains usable when content grows or wraps
